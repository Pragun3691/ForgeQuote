## Boundary and failure fixtures (write assertions before code)

- Annual pre-GST quotation value `₹25,00,000.00`: **does not** require sales-head approval (word is **exceeding**).
- Annual pre-GST quotation value `₹25,00,000.01`: **does** require approval.
- Margin `100%` or greater: reject; negative margin: reject.
- Missing effective rate: error; no silent rate=0.
- Exact effective_to date: earlier rate no longer active; new rate effective_from date active.
- Two overlapping rate windows for same key: reject.
- After updating machine rate, already-issued quote and PDF remain unchanged.
